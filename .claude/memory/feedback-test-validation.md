---
name: feedback-test-validation
description: 不要把单元测试通过当作功能验证通过，不要编造测试结果展示给用户
type: feedback
---

**规则: 验证必须是真实的功能测试，不是静态代码分析**

**Why:** 之前我多次展示"测试通过"实际上是代码静态分析，不是端到端功能验证。例如航班查询场景中，我展示的表格是编造的，不是 Agent 实际输出。

**How to apply:**
- 端到端测试必须实际运行 Agent.think() 并验证返回内容
- 不要把组件单元测试（import、类方法存在）当作功能正常
- 验证时展示真实输出，不要只描述"符合预期"
- 如果不确定实际效果，直接承认并运行验证
